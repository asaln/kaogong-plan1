    如何获取 Supabase 配置：

    1. 打开 supabase.com，用 GitHub 账号注册（免费）

    2. 点击 "New Project"，创建一个项目（地区选离你近的）

    3. 进入项目后，左侧菜单点 "SQL Editor"，粘贴下方 SQL 建表语句并执行：

    create table kaogong_data (
  id bigserial primary key,
  user_id text not null,
  data jsonb not null,
  updated_at timestamptz default now(),
  unique(user_id)
);
alter table kaogong_data enable row level security;
create policy "Users manage own data" on kaogong_data
  for all using (user_id = auth.uid()::text) with check (user_id = auth.uid()::text);

    4. 进入 Settings → API，复制 Project URL 和 anon public key

    5. 填入上方输入框，点保存即可

    注意：本页面不存储你的密钥，配置只存在你本机浏览器中。

    📖 使用说明

    ① 打卡：每天"任务清单"里每项任务前都有复选框，点一下即标记完成（文字自动划线变灰）。

    ② 进度：勾选后当天"完成度"自动算百分比，勾满当天 → 整行变绿；勾一部分 → 变黄。顶部四阶段进度条同步变长。

    ③ 修改任务：直接点击任意任务文字即可编辑，按 Enter 保存，Shift+Enter 换行。修改后自动保存到本地。

    ④ 筛选：用顶部筛选栏按阶段/类型/完成状态快速定位某天；搜索框支持按日期片段检索（如输 2026-11 看11月）。

    ⑤ 排序：点击表格表头可按该列排序（如按完成度升序，找出还没开始的天）。

    ⑥ 打印：点"打印"可打印当前筛选结果，贴墙对照使用。

    ⑦ 多端同步：在"云同步设置"标签页配置 Supabase 或 LeanCloud，即可实现多设备数据同步。不配置也能正常使用本地功能。

    ⑧ 时间：所有时间写进任务描述（如 06:50-07:15），不做时区换算。

    ⑨ 改任务：点任务文字直接编辑，支持换行（Shift+Enter）。也可点当天右侧「✎ 编辑」整行重写、点「🗑」删除当天。

    ⑩ 备份：重要进度请定期点「⬇ 导出备份」存一份 JSON 文件，换设备后用「⬆ 导入备份」读回。
